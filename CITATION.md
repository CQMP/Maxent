# Citing Maxent

If Maxent contributes to published research, cite the Maxent method paper and the latest ALPS framework paper below.

## Method paper

R. Levy, J. P. F. LeBlanc, and E. Gull, “Implementation of the maximum entropy method for analytic continuation,” *Computer Physics Communications* **215**, 149–155 (2017). [doi:10.1016/j.cpc.2017.01.018](https://doi.org/10.1016/j.cpc.2017.01.018) ([arXiv:1606.00368](https://arxiv.org/abs/1606.00368))

## Framework paper

B. Bauer *et al.*, “The ALPS project release 2.0: Open source software for strongly correlated systems,” *Journal of Statistical Mechanics: Theory and Experiment* **2011**, P05001 (2011). [doi:10.1088/1742-5468/2011/05/P05001](https://doi.org/10.1088/1742-5468/2011/05/P05001)

## Core libraries

Versions of Maxent built on ALPSCore should also cite:

A. Gaenko *et al.*, “Updated core libraries of the ALPS project,” *Computer Physics Communications* **213**, 235–251 (2017). [doi:10.1016/j.cpc.2016.12.009](https://doi.org/10.1016/j.cpc.2016.12.009)
