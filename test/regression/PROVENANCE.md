# Provenance of the references

**original numerics** of Maxent, before any modernization of the code.
The same information is stored as `provenance.*` attributes at the root of
every reference file.

## Determinism

Two independent generations with the reference build were compared with
`compare.py --report`: all 1165 datasets (1157 numeric, 8 text) in 56 cases
were bit-identical.

## Variant builds (tolerance measurement)

The tolerances in `tolerances.json` were set from the differences between the
reference build and these builds of the same baseline (see
[`MANIFEST.md`](MANIFEST.md) and [`REFERENCE_CHANGES.md`](REFERENCE_CHANGES.md)):

| Variant | Difference from the reference build |
|---|---|
| `-O0` | AppleClang, `-DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_FLAGS_DEBUG="-O0 -g"` (appended after the forced `-O2`) |
| LAPACK | `-DUSE_LAPACK=1` (OpenBLAS 0.3.34 `dgesvd` instead of Eigen `JacobiSVD`), run with `OPENBLAS_NUM_THREADS=1` (multi-threaded OpenBLAS in 8 parallel runs oversubscribes the machine) |
| clang 22 | MacPorts `clang++-mp-22`, system libc++ |
| GCC 15 | MacPorts `g++-mp-15`, libstdc++, against an ALPSCore built with GCC 15 (MPI off). Needs `-include algorithm` (ALPSCore bug; fix proposed upstream in ALPSCore/ALPSCore#667) and a baseline copy without `-msse2` (B3). |

With the final tolerances, the LAPACK, clang 22 and GCC 15 builds pass all 56
cases, and the `-O0` build passes all cases except `legendre` (full size),
which did not finish within 30 minutes.

## Detection check

An older build of the same code that (a) lacks the B7 fix and (b) integrates
the Legendre kernel with Boost Gauss-Kronrod instead of GSL was compared
against the references:

* `t_kernel_time_bosonic` fails (spectra change by ~1e-5 relative, chi2 by 5e-4),
  and so does `kernel_time_bosonic` in `components.h5` (2.2e-3). No other
  case fails.
* The Legendre kernels agree with the GSL ones to 2e-16, so (b) is not a
  numerical change; the Legendre end-to-end cases stay within tolerance.
